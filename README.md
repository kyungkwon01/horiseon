Horiseon Refactored Website

Project Overview

This project involves the refactoring of the Horiseon website to improve accessibility, adhere to web standards, and enhance overall performance. The goal is to ensure that the website is optimized for users with disabilities and provides a seamless user experience across all devices.

Changes Made

The following changes have been made to the website:

- Implemented semantic HTML elements to improve accessibility and enhance search engine optimization (SEO).
- Added alt text to images for better accessibility and improved user experience.
- Updated CSS selectors and properties to follow a semantic structure, ensuring better code organization and maintainability.
- Removed duplicate declaration blocks with identical properties to improve performance and reduce file size.

Accessibility Features

The website has been optimized for users with disabilities with the following features:

- Screen reader compatibility: Users with visual impairments can navigate the website using assistive technologies.
- Keyboard accessibility: Users can navigate the website using only their keyboard.
- Video captions: All videos on the website have captions to enhance accessibility.
